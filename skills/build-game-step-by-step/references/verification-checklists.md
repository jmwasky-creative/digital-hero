# 游戏验收清单

## 目录

1. 自动化检查
2. 浏览器玩家路径
3. 随机与关卡
4. 音频
5. 响应式与可访问性
6. Git 与服务交付

## 1. 自动化检查

- 语法、类型和格式检查通过。
- 领域模型覆盖合法变化、边界和非法操作。
- 随机生成器覆盖范围、不变量、seed 复现和近期排重。
- 存储失败、音频缺失和离线状态能安全降级。
- 静态路径不能越界，接口输入有校验。
- 测试没有通过放宽真实约束来“修复”失败。

## 2. 浏览器玩家路径

至少执行：

1. 首次进入与开始；
2. 自动读题延迟；
3. 点击或拖动一个错误选项；
4. 确认错误不会修改状态；
5. 选择正确选项；
6. 检查每个实体逐个变化；
7. 回答错误并重试；
8. 回答正确；
9. 补回多个实体时逐个增加；
10. 完成、进入下一关和整轮重玩。

分别保存开始、进行、错误、正确、完成状态的 DOM 或截图证据。

## 3. 随机与关卡

- 连续启动两轮时数字会变化。
- 刚刚使用的题目不会立即重复。
- 同一轮的关卡指纹不重复。
- 每题正确选项存在且唯一。
- 选项数量符合设计，干扰项不重复。
- 目标数量适合当前画面容量。
- 最后一关和中间关按钮文案不同。
- 所有关卡标题、场景、语音和目标名称来自数据。

## 4. 音频

- 用户首次点击后音频成功解锁。
- 点击数字会读出数字或数量。
- 读题、正确、错误、掉落和完成不会互相取消。
- 音效音量安全，连续触发没有明显爆音。
- 关闭语音或浏览器不支持语音时流程不锁死。
- 页面隐藏、重开和切关会停止旧语音。

## 5. 响应式与可访问性

- 横屏和竖屏都能看到核心操作。
- 操作卡不会遮挡目标、角色或按钮。
- 触控目标不小于约 56×56 CSS px。
- 所有按钮有准确、动态的无障碍名称。
- 禁用状态、焦点和错误提示可感知。
- 减少动态效果偏好能生效。

## 6. Git 与服务交付

- 查看 `git status`，保留用户的无关修改。
- `git diff --check` 通过。
- 提交信息说明行为变化。
- 只在用户授权或既定流程要求时推送。
- 服务启动后检查真实健康地址。
- 服务关闭后确认端口已释放。
- 最终回复说明测试数量、浏览器路径、提交哈希和服务状态。
