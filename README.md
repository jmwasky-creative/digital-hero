# 小鸡数字积木新家

面向 4.5～6 岁儿童的离线优先数字积木游戏。数学学习通过“看得见、摸得着”的积木数量变化完成，而不是把加减法题目换一层皮。

当前版本实现了第一个可玩技术切片：

1. 小鸡需要 8 块积木搭屋顶，画面从 5 块开始；
2. 儿童点击或拖动数字积木 `[3]`，它展开为 3 块单位积木并逐块吸附；
3. 风吹落 2 块，儿童回答“还剩几块”；
4. 答对后补回 2 块，屋顶完成。

其中数量由 `QuantityModel` 统一维护，动画和音效只表现已经提交的数量变化。数字点击会朗读，积木吸附、数量变化、掉落、答对、答错和建造完成均有合成音效；答错采用柔和重试音，不使用警报音。

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm run dev
```

然后访问 [http://127.0.0.1:3000](http://127.0.0.1:3000)。

```bash
npm test
```

测试覆盖数量不变量、十积木组合/展开、可复现随机出题、反重复规则、本地存储降级、音频降级、静态服务、事件幂等与服务重启后的事件恢复。

## 目录

```text
public/
  app.js                 首个儿童可玩切片
  styles.css             竖屏优先的儿童界面
  game/
    quantity-model.js    数量唯一事实源
    task-generator.js    固定种子与规则出题
    audio-manager.js     Web Audio 合成音效与语音
    storage.js           IndexedDB / localStorage Outbox
  sw.js                  离线静态资源缓存
server.js                零依赖 Node 静态服务与最小同步 API
tests/                   领域与集成测试
```
